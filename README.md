# Museum of Seeing Prototype

Static prototype for a children's aesthetic learning app inspired by open museum collections.

## What's inside

- `index.html`: app shell and screens
- `styles.css`: visual system and responsive layout
- `main.js`: prototype state and screen transitions

## Prototype flow

- Map
- Mission
- Studio
- Collection
